# szymonograbek/homebrew-tap

Homebrew casks for my macOS apps.

```sh
brew install --cask szymonograbek/tap/<app>
```

| App | Install |
| --- | --- |
| [Bee](https://github.com/szymonograbek/bee): menu bar app that keeps your Mac awake | `brew install --cask szymonograbek/tap/bee` |

Casks are updated automatically by each app's release workflow.
